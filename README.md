# Matchday Arcade

Four sports games that run in the browser. Nothing to install.

**Play:** https://ardayuzak888.github.io/matchday-arcade/

| Game | Sport | Players |
| --- | --- | --- |
| Hoops | Basketball shootout, 60 seconds | 1 |
| Derby Day | 1-on-1 football match with goalkeepers | 1 vs CPU or 2 on one keyboard |
| Spot Kick | Penalty shootout, best of 5 + sudden death | 1 vs CPU |
| Puck Rush | Air hockey, first to 7 | 1 vs CPU or 2 on one screen |

Works with mouse, keyboard and touch. Best scores are saved in your browser.

## Run locally

Open `index.html` in any modern browser.
